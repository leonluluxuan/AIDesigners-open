# Changelog

All notable changes to this repository are recorded here.

The format follows the principles of [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). Version numbers describe the public repository and workflow contract, not the private hosted service.

## [0.1.0] - 2026-11-03

### Added

- Public `aidesigner-workflow/v1` contracts and workflow Skill.
- JSON Schemas and examples for image generation, jobs, video remake plans, and ecommerce module plans.
- Hosted Agent API client, CLI, and local stdio MCP server.
- Independent provider-adapter interfaces and example documentation.
- Local mock server and conformance tests.
- Public security, contribution, conduct, and license documentation.
